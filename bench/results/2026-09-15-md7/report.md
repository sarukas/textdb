## Accuracy checks (untimed)

These run outside every timed span, before and after each cell. They exist so a backend cannot post good latencies for work it did not do. **A cell that fails any check publishes no timings at all** — its latency rows are withheld and counted under `timings voided`.

| clean_start | store empty before the suite ran | 3 pass | 3 pass | 3 pass |
